# Petshop Meu Amigo Fiel

Projeto acadêmico desenvolvido por Demetrius Souza Telles para a
Fase 1 da disciplina Fundamentos de Sistemas Web.

## Objetivo

Desenvolver um site em HTML para apresentar os produtos e serviços
de um petshop, com navegação entre páginas e informações claras
sobre descrições, preços e disponibilidade de tele-busca.

## Funcionalidades

- Página inicial com apresentação do petshop.
- Catálogo com seis produtos, distribuídos em três categorias:
  acessórios, rações não perecíveis e higiene e limpeza.
- Imagem, descrição e preço de cada produto.
- Apresentação dos serviços de banho e tosa.
- Opções de serviços com e sem tele-busca.
- Navegação entre as páginas e acesso ao contato no rodapé.

## Estrutura do projeto

- index.html: página inicial.
- produtos.html: catálogo de produtos.
- servicos.html: descrição e preços dos serviços.
- imagens/: imagens utilizadas no catálogo.
- README.md: documentação do projeto.

## Tecnologia utilizada

HTML5, sem CSS, Bootstrap ou JavaScript, conforme os requisitos
da Fase 1.

## Como visualizar localmente

1. Baixe ou clone este repositório.
2. Abra o arquivo index.html em um navegador.
3. Utilize os links do menu para acessar produtos e serviços.

Mantenha os arquivos HTML e a pasta imagens na estrutura original
para que os links e as imagens funcionem corretamente.

## Observações

Este projeto apresenta um petshop fictício, sem comercialização real.
Os preços e o contato são demonstrativos.

O site não realiza compras, pagamentos ou agendamentos nesta fase.
